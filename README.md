# 🎟️ VibeVerse – Entertainment Booking Website

**VibeVerse** is a modern entertainment booking website designed to help users discover and book exciting entertainment experiences such as **concerts, music festivals, live events, and more**.

The project focuses on creating a visually attractive, user-friendly, and responsive entertainment platform using front-end web technologies.

## ✨ Features

* 🎵 Modern and attractive homepage
* 🎤 Upcoming events section
* 🎟️ Event ticket booking
* 💳 Demo payment section
* 🧾 Digital ticket confirmation
* 🔐 Login and Sign Up sections
* 💰 Automatic ticket price calculation
* 📱 Responsive design for different screen sizes
* ⚡ Smooth scrolling and interactive buttons
* 🌙 Dark-themed UI with a purple/black aesthetic

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **Tailwind CSS** – Styling and responsive design
* **JavaScript** – Interactions, booking logic and price calculation

## 🎯 Project Objective

The main objective of VibeVerse is to create a simple and engaging online platform where users can explore entertainment events and experience a smooth ticket-booking journey.

## 🔄 Website Flow

```text
Home
  ↓
Explore Events
  ↓
Select Event
  ↓
Book Tickets
  ↓
Payment
  ↓
Booking Confirmation
  ↓
Digital Ticket 🎟️
```

Users can also access:

```text
Login → Sign Up → Account Access
```

## 🎨 Design

VibeVerse uses a **dark and modern interface** with purple highlights to create a premium entertainment-inspired look. Event cards, buttons, hover effects, and smooth scrolling make the website more interactive.
